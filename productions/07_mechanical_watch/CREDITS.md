# Mechanical watch credits

The delivered preview uses real sample-based SFX with playback-rate changes and granular layering. Clock ticks are cemkalyoncu's CC0 recordings from https://opengameart.org/content/tick-and-tock. The motor layer is qubodup's CC0 fan recording from https://opengameart.org/content/defect-motor-loop. Mechanical accents are Brian MacIntosh / BMacZero's CC0 sample from https://opengameart.org/content/mechanical-sounds.

Full file attribution is in ../../assets/sfx/CREDITS.md. watch_rewind.wav is a reversed derivative of fan_interval.wav. gen_sfx.py and tools/audio_mix.py reproduce audio_mix.wav used in preview_sfx.mp4.

All visual geometry and camera animation are authored for this production with the bundled MIT-licensed Three.js runtime.
