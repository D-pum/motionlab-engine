# Viz 3D production lessons

## 2026-11-18 Check the encoded export for glyphs and framing

Use explicit UTF-8 when editing scene files. Sample the actual MP4 for titles,
currency signs, arrows and units after the last code change. A source edit
corrupted glyphs that had rendered correctly in the initial preview, and a
long title clipped in the first gravity-assist review. Check the title
bounds at each scene change and compare the final sampled frames with the
approved labels.
